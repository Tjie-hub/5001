# C-007 · HSC-driven IHSG exclusion: one-shot market-design event window

**Status: PROPOSE-ONLY as a RECORD. Not registrable as a test — N=1 by construction.**

## 1. Mechanism
BEI will remove ~80 High-Shareholding-Concentration names (~18% of IHSG weight; BREN, TBIG, MTEL among them,
TOWR excluded) from the IHSG calculation following the MSCI criteria alignment (announced ~2026-10-19; effective
date NOT yet set — macro_watch is alerting on it). When the date lands, tracker/mandate portfolios benchmarked to
IHSG must sell the removed names and buy the retained/restored ones — a scheduled, rule-based forced-flow event
(C1/C2 family) at market scale, observable once. M4.1 benchmark-replication flow.

## 2. Falsifiable prediction
Around the effective date: removed names underperform the non-IHSG-matched book into the event (predictable
selling), recover after (index-flow release) — the classic deletion effect. As N=1 it cannot clear a bar; the
prediction is recorded for the archive, not risked.

## 3. Data
Event dates: BEI announcement (blocked from this machine — owner-browser item; secondary coverage exists in
macro_watch's tracked topics). Holdings: the HSC list is derivable from KSEI concentration fields + BEI's
published list (owner-browser or news [S]). Prices: 5001 ohlcv daily; the jurnal26 monitors already watch BREN
pre-open. All present except the date itself.

## 4. Counts and prior-only power
N = 1 event, ~80 names. No t-test is meaningful (single cluster). **UNDERPOWERED by construction — do not
register a test.** What IS powered: the analogous reconstitution windows (C2) were marginal precisely because
N=26×7; the exclusion-effect direction is documented in-repo as real-but-untradeable (C1 ADD-side). The value
here is a recorded observation of a regime change in IHSG's construction, feeding future index-flow designs.

## 5. Non-overlap proof
Nearest rows: **C1/C2** (IDX quarterly reconstitution — routine, FAILED/marginal; this is a one-time
criteria-driven exclusion wave, different rule); **B14 {S}** (sector momentum — unrelated). No prior arm covers
an IHSG-methodology change.

## 6. Cost / capacity
As a record: zero. As a trade: deletion-side = long-only avoidance of removed names into the date + long restored
names — both legs long-only feasible, execution at close, ADV large (big caps). Not proposed as a trade here.

## 7. Distinctness from the live book
None — orthogonal. It also *changes the benchmark* for every IHSG-excess endpoint once effective (a book-level
accounting note the owner should be aware of, independent of any test).

**Recommendation: record, don't test.** Add the exclusion date to the owner-browser list; when BEI publishes it,
the prospective monitors capture the window; any testable design (e.g. pooled with future quarterly reviews)
