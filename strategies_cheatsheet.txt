STRATEGIES
───────────────────────────────────────────────────────────────────────
ID  NAME                  ENTRY TRIGGER            TP    SL    WR
 1  Vol-Weighted          VR>1.8 + delta+ + >SMA10 2.0%  1.5%  65%
 2  Momentum Following    2-day streak + VR>1.3    3.5%  2.5%  55%
 3  VWAP Reversion        <VWAP(-1%) + VR>1.3      1.5%  1.0%  67%
 4  Conservative Confirm  VR>1.3 + bullish + >MA20 1.5%  1.0%  70%
 5  Volume Profile POC    Price→POC from above     1.5%  1.5%  65%
 6  Inside Bar Breakout   prev=inside; open>prev_hi ATR×2 prev_lo 60%

NOTE: registry strategy 'ORB' is a daily ATR-around-open approximation
      (not true intraday ORB). For genuine intraday ORB (first 30/60 min
      breakout from ticks table) use engine.strategies.check_orb_intraday_signal().
      Not yet wired into scheduler/screener — manual use only.

───────────────────────────────────────────────────────────────────────
9-LAYER SIGNAL FILTER  (all must pass)
───────────────────────────────────────────────────────────────────────
 1. Calendar Blackout  — H-1/H+1 around BI Rate RDG & FOMC → skip scan
 2. Sector Rotation    — ticker must be in OVERWEIGHT or NEUTRAL sector
 3. WF Filter          — walk-forward score ≥ 50%
 4. Fundamental        — PE<20, PBV<5, ROE>5%
 5. Flow Confirmation  — Stockbit flow score ≥ +2
 6. Technical          — VR>1.3, VWAP align, ATR normal
 7. WF Consistency     — win rate ≥ 50%, Sharpe ≥ 0.8
 8. Regime (ML)        — TRENDING or SIDEWAYS (not UNCERTAIN)
 9. Weekly Trend (MTF) — close ≥ MA20W and MA20W slope ≥ -1%

───────────────────────────────────────────────────────────────────────
KEY INDICATORS  (quick values)
───────────────────────────────────────────────────────────────────────
VR   Volume Ratio = cur_vol ÷ MA20_vol   →  <1.0 avoid, >1.3 ok, >1.8 strong
VPIN Informed-trader proxy 0-1+          →  <0.3 quiet, 0.5-0.7 good, >0.8 danger
RSI  Momentum 0-100                      →  <30 oversold, >70 overbought, 50 neutral
ATR  14-period volatility                →  used for dynamic TP/SL sizing

ML REGIME:
  TRENDING  → all 6 strategies, TP +0.5%
  SIDEWAYS  → VWAP Reversion & Conservative only, TP -0.5%
  UNCERTAIN → no entry, wait

───────────────────────────────────────────────────────────────────────
SECTOR ROTATION  (/api/sector/rotation)
───────────────────────────────────────────────────────────────────────
Score = 0.5×ret5D + 0.3×ret10D + 0.2×ret20D  (per sector)
  OVERWEIGHT  (top 3)   — full signals allowed
  NEUTRAL     (mid 5)   — signals allowed
  UNDERWEIGHT (bot 3)   — new entries blocked

───────────────────────────────────────────────────────────────────────
ECONOMIC CALENDAR  (/api/calendar/status)
───────────────────────────────────────────────────────────────────────
Blackout window = H-1, event day, H+1
  BI Rate RDG 2026: Jan15 Feb19 Mar19 Apr23 May21 Jun18
                    Jul16 Aug20 Sep17 Oct15 Nov19 Dec17
  FOMC 2026:        Jan28 Mar18 Apr29 Jun17 Jul29 Sep16 Oct28 Dec16
  → Scans auto-pause + Telegram alert on blackout days

───────────────────────────────────────────────────────────────────────
WEEKLY TREND FILTER  (multi-timeframe)
───────────────────────────────────────────────────────────────────────
Pass: close ≥ MA20W  AND  MA20W slope ≥ -1% (over last 5 weeks)
Fail: signal blocked, reason prefixed W-BLOCK:
      insufficient data (<100 bars / <22 weekly bars) → pass-through

───────────────────────────────────────────────────────────────────────
RISK MANAGEMENT
───────────────────────────────────────────────────────────────────────

Commission: buy 0.15%  sell 0.25%  |  Slippage 0.1%
Size: qty = (50M × 30%) ÷ entry_price

token = Path(".stockbit_token").read_text().strip()

ohlcv_all, ticks_all = fetch_all_stockbit(tickers, token)

saved = save_ohlcv_to_db(ohlcv_all, date.today().isoformat())

EOF

COMMON MISTAKES
───────────────────────────────────────────────────────────────────────
✗ Entry below SMA10/20/50        → wait for full alignment
✗ VR < 1.3x                      → weak signal, skip
✗ VPIN > 0.8                     → reversal risk, wait for pullback
✗ Trading UNCERTAIN regime        → hold, wait 1-2 bars
✗ Ignoring blackout day          → system auto-blocks, trust it
✗ Entering UNDERWEIGHT sector    → system auto-blocks, trust it
✗ Position > 30% capital         → max 15M IDR per trade
